# U60-Pro-WebUI 使用说明

适用于中兴 U60 Pro（MU5250），已在国行固件 `BD_CNMU5250V1.0.0B31` 上验证。

- 控制台：`http://192.168.0.1:8080`（默认中文，在“系统 → 设置 → 外观”里可以切换英文）
- Agent API：`http://192.168.0.1:9090`（控制台通过它管理设备）
- SSH：`ssh -p 2222 root@192.168.0.1`（只允许密钥登录）

安装、解锁和固件升级后的恢复步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)，安全规则见 [SAFETY.md](SAFETY.md)。

---

## 首页

信号、网络模式、实时速率、电池、流量统计都在这一页，每 3 秒刷新一次。出现告警（温度过高、电量低、充电控制失败等）时会在顶部显示。

## 代理（mihomo）

### 添加订阅

1. 代理 → 订阅 → 添加订阅，填名称和订阅链接。
2. 打开“使用订阅自带的规则与分组”时，直接使用机场提供的完整配置（策略组、规则、规则集）；关闭时，订阅只作为节点来源，分流规则用“设置”里的预设。
3. 订阅会按设定的间隔自动更新，也可以手动点“更新”。

> 订阅链接里带有你的 token，请不要截图或分享。如果泄露了，到机场官网重置订阅链接，再在这里“编辑”换成新链接。

### 选择节点

代理 → 节点：每个策略组一张卡片，点节点即可切换（只有“手动选择”类型的组可以点）。“全部测速”会测所有节点的延迟，自动选择组会据此挑最快的节点。

### 让设备走代理

有三种方式：

| 方式 | 适合 | 怎么做 |
|---|---|---|
| 透明代理（TUN） | 所有连到路由器的设备都不用设置 | 代理 → 设置 → 打开“透明代理（TUN）”，重启后会自动恢复 |
| 自动代理（PAC） | 只想让个别设备走代理 | 在设备的 Wi-Fi 设置里填 PAC 地址 `http://192.168.0.1:9090/proxy.pac` |
| 手动代理 | 电脑上的个别程序 | HTTP / SOCKS5 地址 `192.168.0.1:7890` |

**国内流量绕过 TUN**（默认开启）：访问中国大陆 IP 的连接不经过 mihomo，直接走路由器的硬件转发。实测国内下载从约 90 Mbps（mihomo 占满一个 CPU 核）提高到 138–195 Mbps（mihomo 几乎不占 CPU），也更省电。如果订阅规则里有“某些大陆 IP 走代理”的特殊需求，可以在 代理 → 设置 里关闭。

### zashboard 面板

在 代理 → 设置 → 管理面板 里点“打开 zashboard”，会自动连上路由器上的 mihomo（链接里带了地址和密钥），可以看实时连接、日志、规则，手动更新规则集和代理集。也可以直接打开 `http://192.168.0.1:9097/ui/`，然后手动填写地址 `192.168.0.1`、端口 `9097` 和密钥。面板里的“升级内核”和 TUN 开关被隐藏了，这两项由控制台管理。

- 密钥：订阅配置里写了 `secret` 就用它（控制台的同一张卡片上可以复制）；没写就是**无密码**。
- 局域网里任何能打开这个页面的设备都能控制代理。需要密码时，在订阅配置里加上 `secret`。
- 面板文件由 `scripts/deploy-mihomo.sh` 安装（固定版本并校验），重新运行它就会更新。

### 出问题时

- 概览页的“转发正常 / 转发异常”是看门狗每分钟检测的结果。mihomo 连续转发失败会被自动重启；仍然不行时会自动关闭 TUN，设备恢复直连，不会断网。
- 固件开机时会把北京时间当成 UTC 写进系统时钟（快 8 小时），守护脚本随后把它校正回 UTC。mihomo 用自己的 NTP 每分钟校时一次，所以系统时钟被改动后，依赖时间校验的节点（SS2022、REALITY 等）最多一分钟内恢复。

## 网络

### 终端

- **设备管理**：可以重命名设备、断开 Wi-Fi 设备、把设备加入 Wi-Fi 黑名单（拉黑后它连不上主网络和访客网络，解除拉黑后恢复）。拉黑只影响 Wi-Fi，USB-C 连接的设备不受影响。
- **流量**：每台设备旁边显示上网流量（↓ 下载 ↑ 上传）和当前速率，数据来自内核的连接跟踪，硬件加速的流量也会统计在内。可以随时清零。

### Wi-Fi

- 2.4 GHz / 5 GHz 分别设置名称、密码、信道、频宽、发射功率；修改会让 Wi-Fi 重启，保存前会提示。
- **访客网络**：独立的访客 Wi-Fi，可以设置密码和时间限制（2/4/8/12 小时或永久）。开放网络（无密码）必须设置时间限制，到时路由器会自动关闭。

### 路由器

- 局域网地址和 DHCP 范围、DNS。
- **固定 IP 地址（静态 DHCP）**：让某台设备每次都拿到同一个地址，最多 10 条。**路由器重启后生效**。

### 端口

- **端口转发**：把一段外部端口转发到设备的相同端口；**端口映射**：把一个外部端口转发到设备的另一个端口。各最多 20 条，外部端口重叠的规则会被拒绝。
- **UPnP、DMZ、远程管理、响应 ping**。

> 大多数手机卡没有公网 IPv4（多人共用一个地址，CGNAT），这时端口转发和 DMZ 从外网是连不进来的。

## 蜂窝

- **数据**：移动数据开关（断开前会确认，控制台和局域网不受影响）、本月流量、清零日、**每月流量限额**和提醒比例。
- **APN**：添加、编辑、启用、删除手动 APN；修改正在使用的配置前会确认，因为移动数据会重新连接。
- **短信**：收件箱、已发送、发短信、删除。
- **短信转发**：新短信在约 20 秒内推送出去，已有的短信不会转发。支持：

| 服务 | 需要填写 |
|---|---|
| Bark | Bark App 里的设备密钥，或完整推送网址 |
| Server酱 | SendKey（`SCT…`） |
| 企业微信群机器人 | 机器人的 Webhook 网址 |
| Telegram | 机器人 Token 和 Chat ID；国内网络请打开“通过代理发送” |
| 自定义 Webhook | 任意网址，收到 `{"title","text","device"}` JSON |

  保存后可以“发送测试”。密钥只保存在路由器上，之后不会再显示。

## 信号

- 每个载波的 PCI、频点、RSRP/RSRQ/SINR。
- **模式与锁定**：网络模式、锁频段、锁小区。
- **运营商选择**：搜索附近的网络并手动注册（搜索时移动数据可能暂停 1–3 分钟），随时可以“恢复自动选网”。

## 系统

- 设备、SIM 卡信息（含 PIN 码锁状态和剩余次数；修改 PIN 请用原厂网页）、路由器时钟。
- **USB 模式**：B31 固件去掉了 ECM/RNDIS 切换接口，只能保持 ECM。
- **休眠与定时重启**：空闲多久后休眠（会关闭 Wi-Fi）；每周某天或每隔 N 天在指定时间重启，可设置随机延迟。
- **断网看门狗**：定期 ping 一个地址，连续失败就自动重启路由器，用来恢复卡死的移动网络。保存时路由器会先确认这个地址能 ping 通（约 10 秒）。
- **备份与恢复**：把上面这些设置和代理订阅保存成一个文件，恢复出厂或升级固件后可以导回去。文件里有订阅链接和推送密钥，请妥善保管。

## 极客屏（设备小屏）

设备 3.5 寸触摸屏上的终端风格状态屏，由单独的程序 `zte-screen`（`/data/bin/zte-screen`）绘制。会话期间它会暂停原厂界面，退出、出错或崩溃时一律自动恢复原厂界面。详细原理见 [SCREEN.md](SCREEN.md)。

- **页面**：底栏 HOME（陪伴角色咕嘎、简要状态与 WAN、告警）、SYS（每核 CPU、内存、进程）、PWR（电池电压电流、健康度、所有温区）、CELL（RSRP/SINR 等信号与曲线）、NET（上下行速率、各接口、mihomo）、LAN（Wi-Fi 与各终端信号、速率）、PROXY（mihomo 管理，见下）；左右滑动也可以翻页。点右上角时钟打开设置（亮度、空闲时长、空闲后的动作、主题、扫描线、起始页、自动打开）。
- **退出**：点底栏 `:q`，或长按电源键 1.5 秒；短按电源键开关背光。默认空闲 2 分钟后回到原厂界面，由原厂负责熄屏和省电；把“空闲后”设为“熄屏”则只关背光、一直停在极客屏，短按电源键点亮，只有 `:q` 或长按电源键才回到原厂界面。
- **打开方式**：系统 → 设置 → 极客屏 → 在设备上显示；在亮着的原厂界面上双指按住不动 2 秒；或把“自动打开”设为“开机时”（每次开机一次）或“每次亮屏”（原厂界面每次点亮屏幕后自动切换，点 `:q` 回到原厂界面后，下次熄屏之前不会再切）。
- **咕嘎**：HOME 上方住着 DeepSeek 的女仆鲸鱼娘咕嘎，形象来自你给的参考图，表情由 Codex 在原图上只改脸部生成。她按作息在六个场景里过一天：卧室小屋（23–6 点）、电车（7–8 点和 17 点）、算力机房（9–11 点）、女仆咖啡厅（12–13 点和 21–22 点）、图书馆（14–16 点）、天台（18–20 点），每个场景都有清晨/黄昏、白天、夜晚三种光线和各自的小动画（阳光里的浮尘、咖啡机的热气、机柜指示灯、车窗外掠过的树和电线杆、夜里的星星和串灯等）；点标题栏可以带她去下一个场景，到下一个作息时段再自动回到作息里。只用点击互动：摸头、戳身体（连戳会生气）、点场景里别处会吓她一跳、点对话气泡跳过或收起。她会自己晃悠、哼歌，对充电、低电量、发热、新设备连入、网速飙升、信号变弱等吐槽两句，离开 20 分钟后回来会打招呼，深夜会打瞌睡（点一下叫醒）。没有喂食和等级。
- **PROXY 页**：mihomo 的模式、实时速率和连接数、各策略组当前选择和延迟；点策略组看节点列表，点节点立即切换（只有切节点不用确认），可以对单个组或全部节点测速；“连接”看最忙的连接走了哪个组、哪个节点、哪条规则；“订阅”看服务状态和各订阅的节点数、更新时间、流量和到期日。切换模式、重启 mihomo、更新订阅都会先弹框确认，再交给 agent 执行（和网页后台走同一套逻辑，所以模式会保存）。
- **咕嘎的台词**：在 `/data/local/tmp/zte-pet.json`（权限 600）里写上 `base_url`、`api_key`、`model`（可选 `name`、`user`、`per_hour`），她就会调用这个模型说话；没有这个文件或调用失败时用内置台词。模型只能看到一行只读的设备摘要（不含 IP、IMEI、设备名），不能操作路由器，回复只会显示在气泡里。默认每小时最多 60 次请求。
- **部署**：`./deploy-screen.sh --dry-run` 检查，`./deploy-screen.sh` 安装。

## 常见问题

**控制台打不开？** 确认设备连着路由器（Wi-Fi 或 USB），访问 `http://192.168.0.1:8080`。如果只有控制台打不开，可以 SSH 登录后查看 `/data/local/tmp/zte-agent.log`。

**开了 TUN 以后某台设备上不了网？** 先在 代理 → 设置 里关闭 TUN 确认是不是代理的问题；看门狗也会在 mihomo 失效时自动关闭 TUN。

**升级固件后功能没了？** 固件升级会清空 `/etc`，按 [DEPLOYMENT.md](DEPLOYMENT.md) 重新部署，再用“备份与恢复”导回设置（`/data` 下的代理配置一般会保留）。
